# Microphone

Shows how loud it is, as a bar on the Serial Monitor.

## What you should see

Open the Serial Monitor at 115200 baud, then talk or clap and watch the bar grow.

**Pins:** PDM microphone (LMD2718): CLK 40, DATA 39.

## Run it

Open `Microphone.ino` in the Arduino IDE and upload it. The board settings and the full setup steps
are in the [hardware test README](../README.md). Library needed: none.
